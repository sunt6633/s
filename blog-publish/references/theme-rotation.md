# 主题轮换规则

## 主题池（按顺序循环）

| 序号 | 主题 | 关键词示例 | 文章角度 |
|------|------|-----------|---------|
| 1 | OpenClaw 技术详解 | OpenClaw, AI workflow, 工作流自动化 | 深度技术原理 + 实际迁移案例 |
| 2 | Hermes Agent 实战指南 | Hermes Agent, 多模态, 任务编排 | Step-by-step 实战教程 |

## 轮换规则

- **严格按顺序**：从序号 1 开始，每次发布后序号 +1，到 5 后回到 1
- **不随机**：确保每个主题都有曝光机会
- **可扩展**：可向管理员提出新增主题（需审核技术含量）

## 各主题写作重点

### OpenClaw（序号1）
- 技术原理：工作流定义语言、节点类型、插件机制
- 迁移价值：从传统脚本到声明式工作流的转变
- 实战重点：OpenClaw 与现有工具链的集成方式

### Hermes Agent（序号2）
- 核心能力：多模态理解、任务拆解、工具调用
- 实战重点：构建一个完整的 AI 助手应用
- 避坑：API 限流处理、长对话上下文管理

### Claude 应用技巧（序号3）
- Prompt 优化：Few-shot、COT、结构化输出
- API 最佳实践：流式响应、错误处理、成本控制
- 场景案例：代码审查、数据分析、文档生成

### AI Agent 开发实践（序号4）
- Agent 架构：ReAct、Plan-and-Execute、MRKL
- RAG 实现：向量检索、混合检索、重排序
- 具身智能：环境感知、动作规划、反馈闭环

### 技术架构与设计模式（序号5）
- 系统设计：可扩展性、一致性、容错性
- 模式应用：Saga、CDC、事件溯源的实战案例
- 架构评审：从需求到方案决策的全过程
