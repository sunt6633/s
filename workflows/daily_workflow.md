# 📋 小腾工作流程

## 💰 每日必做

### 1. 开盘前（9:00-9:30）
- [ ] 检查模拟账户持仓
- [ ] 获取自选股行情
- [ ] 更新股票池评分

### 2. 盘中（9:30-15:00）
- [ ] 监控持仓股票价格
- [ ] 触发止盈/止损时告警
- [ ] 记录异动股票

### 3. 收盘后（15:00-18:00）
- [ ] 更新股票池真实行情
- [ ] 生成当日交易报告
- [ ] 分析次日候选股票
- [ ] 执行定时选股任务

### 4. 晚间（18:00后）
- [ ] 生成每日行情报告
- [ ] 备份当日数据
- [ ] 规划次日操作

## 🛠️ 工具使用

### 股票分析流程
```
1. run_stock_analysis.py [股票代码]
2. 查看生成的K线图和资金流向
3. 根据分析结果决定是否建仓
```

### 选股流程
```
1. python stock_selector_v6.py
2. 查看评分排名前10股票
3. 人工确认后建仓
```

### 数据验证流程
```
1. python verify_data.py
2. 检查总资产、盈亏是否一致
3. 如有异常，排查原因
```

## 📊 评估指标

- 模拟账户收益率（目标：跑赢大盘）
- 选股准确率
- 止盈止损执行率
- 最大回撤控制

## 🔄 持续进化

- 每周学习新技术
- 每月总结交易策略
- 每季度评估系统表现
