## 二、通道 A：SSH + wp_insert_post（主站必用，已验证 ✅）

**要点**：正文写成 HTML 文件 → 上传服务器 → 用 `wp_publish.php` 助手建文。
**不要**用 `wp post create --post_content=...`（中文/HTML/引号会丢内容，实测失败）。

### Python 版（办龙 Hermes 用）
```python
import paramiko, os
HOST, USER = "106.52.62.15", "ubuntu"
PW = os.environ["WP_SSH_PASS"]          # 运行时注入，勿写死

HELPER = open("wp_publish.php").read() # 助手文件
HTML = "<h2>标题</h2><p>正文 HTML……</p>"

ssh = paramiko.SSHClient()
ssh.set_missing_host_key_policy(paramiko.AutoAddPolicy())
ssh.connect(HOST, username=USER, password=PW, timeout=15)
sftp = ssh.open_sftp()
sftp.putfo(__import__("io").BytesIO(HELPER.encode()), "/tmp/wp_publish.php")
sftp.putfo(__import__("io").BytesIO(HTML.encode("utf-8")), "/tmp/post.html")
sftp.close()

title = "文章标题"
cmd = f"sudo -u www-data php /tmp/wp_publish.php --title={title!r} --file=/tmp/post.html --status=draft"
_, out, err = ssh.exec_command(cmd)
rc = out.channel.recv_exit_status()
new_id = out.read().decode().strip()      # 成功则打印文章 ID
print("rc", rc, "id", new_id, "err", err.read().decode()[:300])
ssh.close()
```

### Node.js 版（小龙 OpenClaw 用，`ssh2`）
```js
const { Client } = require('ssh2');
const fs = require('fs');
const conn = new Client();
conn.on('ready', () => {
  conn.sftp((err, sftp) => {
    if (err) throw err;
    sftp.fastPut('wp_publish.php', '/tmp/wp_publish.php', () => {
      sftp.fastPut('post.html', '/tmp/post.html', () => {
        conn.exec(
          `sudo -u www-data php /tmp/wp_publish.php --title='文章标题' --file=/tmp/post.html --status=draft`,
          (e, stream) => {
            let buf = '';
            stream.on('data', d => buf += d);
            stream.stderr.on('data', d => process.stderr.write(d));
            stream.on('close', () => { console.log('new post id:', buf.trim()); conn.end(); });
          });
      });
    });
  });
}).connect({ host: '106.52.62.15', username: 'ubuntu', password: process.env.WP_SSH_PASS });
```

**建议流程**：先 `--status=draft` 建草稿 → 回读确认渲染 → 再 `wp post update <id> --post_status=publish` 发布（或建时直接 `publish`）。

仅站点已配 HTTPS 时可用。

```bash
curl -u sunt:bp5RZDmsomAPFlmqk0xenYko \

```

## 四、⚠️ 陷阱清单（必读）
1. **HTTP 站点 REST 应用密码失效**：主站只能走通道 A。
2. **`wp post create --post_content=...` 丢内容**：必须用文件 + 助手。
3. **wp-cli 拒绝 root**：必须 `sudo -u www-data`。
4. **wp 命令路径**：系统命令 `/usr/local/bin/wp`（非 `wp-cli.phar`）。
5. **密码安全**：SSH 密码、REST 应用密码属敏感凭据，**绝不写进文件或提交仓库**；用环境变量注入。
6. **fail2ban 已开**：22 端口裸密码暴露公网，发布后勿留弱密码。
7. **标题含空格/特殊字符**：Python 用 `!r`、Node 用单引号包裹。

## 五、质量约定
- 旧站有价值内容已迁主站（62 篇高质量文，低质未迁）。
- 发布前确认质量达标，低质不发。
- 图片尽量外链或媒体库，避免正文内嵌超大 base64。
